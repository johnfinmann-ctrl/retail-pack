# @platform/camera

Camera Service-kontrakt (fundament) — genbruges af alle apps. Aktiveres kun når en
virksomheds pakkeprofil kræver det. Blokerer aldrig flowet ved fejl (PRS §17/§4.2).

## Status
🚧 Sprint 1 — fundament (kontrakt + ikke-blokerende wrapper). Konkret device-integration
(browser MediaDevices API) tilføjes i den app, der først har brug for det.
