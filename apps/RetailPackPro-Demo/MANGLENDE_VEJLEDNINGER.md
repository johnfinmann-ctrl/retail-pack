# Officielle kædevejledninger, der mangler (v0.5)

Ingen af kæderne har indlæste pakkekrav. Alle står som "Afventer officiel vejledning".
Skemaet viser, hvad der skal fremskaffes og gennemgås, før kravene kan indlæses
og kontrolleres i regelbanken.

| Kæde | Hvad mangler | Modtagelagre i demoen |
|---|---|---|
| Salling Group | Leverandørens logistik-/pallevejledning (gældende version). Eventuelle tillæg pr. format (Netto, Føtex, Bilka) og pr. modtagelager. | Netto Årslev, Netto Køge (krav kan være forskellige) |
| Coop | Leverandørens logistik-/pallevejledning. Afklaring af, hvilket modtagelager der leverer til fx SuperBrugsen Vig. | Ingen endnu |
| Dagrofa | Leverandørens logistik-/pallevejledning og modtagelagre. | Ingen endnu |
| Reitan | Leverandørens logistik-/pallevejledning og modtagelagre. | Ingen endnu |
| Lidl | Leverandørens logistik-/pallevejledning og modtagelagre. | Ingen endnu |

For hvert dokument registreres titel, version, gyldig fra/til og fil. Desuden angives, hvilke
felter vejledningen gør obligatoriske, og afsnit eller side for hvert krav.

## Skal også afklares hos Carletti

- Det præcise format på plukrutens stregkode og på parti-ID'erne på AX-pluklisten
  (demoen kender kun parti-ID'erne på de lokale test-pluklister).
- Om pallelabels med SSCC skal bruges som palle-ID.
- Hvem der er regelansvarlig og kontrollant i drift.
